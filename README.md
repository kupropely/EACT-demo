# ENACT 연구 관리자 설치 안내

## 1. GitHub
기존 저장소 `main` 브랜치의 루트에 `index.html`, `server.js`, `admin.html`, `package.json` 업로드(동일 이름 파일 교체). **기존 `videos/mindfulness.mp4`는 유지**하세요. 영상은 이 ZIP에 포함하지 않았습니다.

## 2. Railway
기존 프로젝트 유지. PostgreSQL 서비스 추가 후 웹 서비스에 다음 Variables 등록:

- `DATABASE_URL`: PostgreSQL 서비스가 제공하는 연결 주소. Railway의 변수 참조 기능을 사용하세요.
- `ADMIN_PASSWORD`: 길고 고유한 관리자 비밀번호
- `SESSION_SECRET`: 32자 이상의 무작위 비밀 문자열
- `NODE_ENV`: `production`

`ALLOWED_CODES`는 자동 발급 방식에서 사용하지 않습니다. `npm start`로 실행됩니다. DB 연결이 실패하면 서버는 시작하지 않습니다.

## 3. 접속
- 참여자: Railway 공개 주소 `/`
- 관리자: Railway 공개 주소 `/admin`
- Google 설문지: `https://forms.gle/rQm7UQiCUhGWsC5U7`

설문지에는 **연구 참여코드** 단답형 필수 문항을 추가하세요. 형식은 `P00001`처럼 **P + 숫자 5자리 이상**입니다.

## 4. 체험 완료 판정
- 통증: 점수 저장
- 걷기: 걷기 마치기 버튼
- 마음챙김: MP4 종료 후 완료 버튼
- 교육: YouTube는 종료 자동 검증이 없고 대상자가 완료 버튼을 누름
- NERO: 준비된 10개 질문 모두 확인

**중요:** 이벤트 기록은 실제 집중 시청/실제 걷기 여부를 보증하지 않습니다. Google Forms 제출 여부는 관리자 화면에서 자동 확인하지 못하며 CSV와 설문 응답 자료를 코드로 대조해야 합니다.

## 5. 설문지 하나 유지 시
Google 설문지는 원래 탭에 두고 ENACT를 새 탭에서 열어 체험하도록 안내하세요. 앱 완료 화면에서 코드를 복사하고 원래 설문 탭으로 돌아가야 합니다. 앱의 `Google 설문지 열기`는 새 설문 탭을 열므로 이전 입력이 복구된다는 보장이 없습니다. 모바일에서 실제 동작을 반드시 테스트하세요.

## 6. 개인정보 및 IRB
휴대전화 번호는 이 앱에서 수집하지 않습니다. 발급코드와 기능별 기록, 접속 시각은 연구자료이므로 연구 설명서/IRB 승인 범위와 보관기간·접근권한을 확인하세요. 관리자 계정 공유를 피하고, Railway 변수나 CSV를 공개하지 마세요.
